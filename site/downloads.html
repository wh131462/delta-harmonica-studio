安装

装好它，再进游戏

Windows 的关键是管理员权限；macOS 与 Linux 各有一道首次打开的系统门槛。

  1. 01

    下载并运行安装包

    运行安装包按向导完成安装；不想写入系统就用便携版，单个 exe 放在任意文件夹，双击即用。

  2. 02

    以管理员身份启动

    右键「以管理员身份运行」，或在应用内点「以管理员重启」并在 UAC 里确认。只试听或排练时不需要管理员权限。

  3. 03

    选择游戏窗口并自检

    刷新窗口列表，选择标题包含「三角洲行动」的窗口；首次使用先跑「输入通道自检」，确认键盘、鼠标中键与组合键都能送达。

  4. 04

    用 F9 开始、F10 急停

    倒计时内切回游戏；游戏用无边框窗口，悬浮窗默认 Ctrl + Alt + O。F10 立即停止并释放所有按下的键。

关键

游戏以管理员权限运行时，Windows 的 UIPI 会静默丢弃普通权限进程的模拟按键。这是「按了开始却没反应」最常见的原因。

  1. 01

    拖进「应用程序」

    打开 dmg，把「三角洲口琴工坊」拖入 Applications。Apple Silicon 选 arm64，Intel 选 x64；zip 版解压后是同一个 app。

  2. 02

    右键「打开」放行

    首次打开在 Finder 里右键应用 →「打开」→ 再点「打开」。若提示「无法检查是否包含恶意软件」，到「系统设置 → 隐私与安全性」点「仍要打开」。

  3. 03

    「已损坏」时清除隔离属性

    在终端执行下面的命令后重新打开；macOS 15 起系统设置里已没有「任何来源」开关。

    xattr -cr "/Applications/三角洲口琴工坊.app"

  4. 04

    用排练模式练熟

    编辑、导入、练习、试听与宏导出都可用；「开始演奏」只按时间轴推进，不发送系统按键，也不会影响游戏。

关键

安装包没有做苹果开发者签名与公证，Gatekeeper 会拦截首次打开。请从官方 Releases 下载，不要用来路不明的重打包版本。

  1. 01

    AppImage 或 deb

    AppImage 先加可执行权限再运行；deb 用 dpkg 安装，依赖缺失时补一次 apt 修复。

    chmod +x delta-harmonica-<version>-linux-x64.AppImage

  2. 02

    缺 FUSE 时换一种启动方式

    Ubuntu 22.04+ 若提示缺少 FUSE，安装 libfuse2，或改用提取模式启动。

    ./delta-harmonica-<version>-linux-x64.AppImage --appimage-extract-and-run

  3. 03

    Wayland 下的悬浮窗

    窗口位置、透明与置顶由桌面合成器决定，全局快捷键也可能被占用；需要稳定的悬浮窗时改用 X11 会话。

  4. 04

    用排练模式练熟

    与 macOS 一致：编辑、导入、练习、试听与宏导出可用，不向游戏注入按键。

关键

Wayland 的悬浮窗限制属于桌面环境差异，不是缺陷；宏文件可以导出并查看，但面向 Windows 宏软件，需按 CSV 时序表自行录入。

已知限制

先看这些，再决定装不装

大部分「打不开」「没反应」都能在这里找到原因和处理办法。

完整平台支持文档
为什么 Windows 版需要管理员权限？

为什么：游戏以管理员权限运行时，Windows 的 UIPI 会静默丢弃低权限进程发来的模拟按键。这是「按了开始却没反应」最常见的原因。

怎么办：右键「以管理员身份运行」，或在应用内点「以管理员重启」并在 UAC 里确认。只试听与排练时不需要管理员。

为什么 macOS 提示「无法打开」或「已损坏」？

为什么：安装包没有做苹果开发者签名与公证，Gatekeeper 默认拦截；「已损坏」通常只是下载后带上的隔离属性。

怎么办：右键应用 →「打开」→ 再点「打开」；或在「系统设置 → 隐私与安全性」点「仍要打开」。仍然不行时按上方安装步骤执行 xattr -cr。

为什么 Linux 的 AppImage 双击没反应？

为什么：AppImage 默认没有可执行权限；Ubuntu 22.04+ 的精简桌面还可能缺少 FUSE。

怎么办：先 chmod +x；缺 FUSE 时装 libfuse2，或加 --appimage-extract-and-run 启动。

为什么 Windows Defender / SmartScreen 会报警？

为什么：安装包与宏都没有代码签名，SmartScreen 对下载量少、无签名的程序会一律提示。这是信誉判断，不是病毒扫描结果。

怎么办：只从官方 GitHub Releases 下载，用 SHA256SUMS.txt 核对哈希；确认无误后点「更多信息 → 仍要运行」。源码全部公开，可以自行审核与构建。

为什么宏和软件内演奏不能同时开？

为什么：两者都会发送按键，同时运行会重复按键、打乱节奏；宏的触发键还可能与软件默认的 F9 冲突。

怎么办：二选一。用宏时把触发键改成鼠标侧键，并让宏软件以管理员权限运行；用软件内演奏时关闭宏。
