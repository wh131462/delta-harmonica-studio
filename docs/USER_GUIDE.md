## 1. 安装与启动

### 安装包用户

1. 运行 `delta-harmonica-0.1.0-x64.exe`（NSIS 安装包）或便携版 `delta-harmonica-0.1.0-portable.exe`。
2. 安装完成后从桌面/开始菜单打开「三角洲口琴工坊」。
3. 程序名在磁盘上是 `DeltaHarmonicaStudio.exe`（Electron 45 对中文 exe 名有原生崩溃 bug，因此可执行文件用英文名；**窗口标题与快捷方式仍是中文**）。

### 源码运行

```bash
npm install
npm run dev        # 开发调试
npm run build      # 构建
npm start          # 运行构建产物
```

### 关于管理员权限

注入游戏按键**必须以管理员身份运行**（游戏是管理员进程，Windows UIPI 会静默丢弃低权限进程的按键）。程序默认以普通权限启动：

- 状态栏左侧显示「权限不足」时，点击右侧「以管理员重启」→ 系统 UAC 弹窗点「是」；
- 重启后状态栏显示绿色「管理员权限」，即可注入；
- 若只试听/排练，不需要管理员权限。

## 2. 游戏内准备

1. **获得「守夜人口琴」**：完成长弓溪谷佐拉任务链（6 阶段，最快约 3 个现实日）→ 邮件领取。
2. **放入 EDC**：局外 `特勤处 → 收藏 → EDC 工具包`，把口琴拖进去（EDC 需行动等级 17 级解锁）。
3. **进入演奏界面**：局内长按 `6` 打开 EDC/工具轮盘 → 选择口琴 → 角色掏出口琴并出现演奏界面（屏幕下方显示音符 1-7+i、按键 Z X C V B N M `,`、鼠标三键「降调/半音/升调」）。
4. **切换到手动演奏**：演奏界面下按 `R` 可在官方自动演奏/手动之间切换；本软件模拟的是**手动按键**，请确保处于可手动演奏状态（官方自动演奏仅播放已解锁曲目，不能导入自定义谱）。
5. **输入法**：把系统输入法切到**英文/半角**，避免逗号被输入法拦截成全角。

> 官方自动演奏（R）是官方功能；本软件的自定义演奏与它是两回事，风险性质不同。

## 3. 第一次运行

### 3.1 风险确认

首次启动会弹出风险声明，必须勾选「我已阅读并理解上述风险」才能进入。

### 3.2 输入通道自检

`设置与校准 → 输入通道自检`（或状态栏/首次提示）：

- 程序会自动把自己切到前台、把鼠标移到窗口中心，然后真实注入：
  `Z` 按下松开 → `X` 按下松开 → 鼠标中键 + `,`（逗号）；
- 窗口内会列出实际收到的事件（正常应收到 6-8 条）；
- 显示「注入链路正常」即通过；
- 若失败：确认程序以管理员运行、没有被安全软件拦截、自检期间不要切换窗口。

> 自检只验证「Windows 输入通道 + SendInput」是否可用，**不能替代游戏内实测**（游戏权限、键位、时序仍需进游戏确认）。

### 3.3 选择游戏窗口

演奏台 → 目标窗口 → 点击「刷新」→ 在下拉框选择标题含「三角洲行动」的窗口（程序会通过进程名 `DeltaForceClient-Win64-Shipping.exe` 自动识别并优先显示 🎮）。

> 若列表里没有游戏窗口：请在 Windows 里把游戏切到窗口化/无边框窗口模式再刷新；独占全屏窗口有时不可枚举。

### 3.4 先试听

选择曲谱 →「试听」按钮：用内置口琴音源本地播放，不发送任何按键，可先确认节奏/音高/移调。

## 4. 完整演奏流程

1. **建议先把鼠标光标移到游戏窗口内**（程序开始时会自动移入一次；演奏中若光标离开游戏窗口会自动停止）。
2. 在游戏中掏出琴、进入可手动演奏状态（见第 2 节）。
3. 回到软件：确认「目标窗口」已选中、速度/移调合适。
4. 如果谱面会用到鼠标左/右键（游戏内为开火/开镜，软件会在界面上提示），勾选**安全确认**「我已在游戏中取出口琴并进入手动演奏界面」。
5. 点击「开始演奏」→ 倒计时（默认 3 秒）内切回游戏。
6. 倒计时结束开始自动演奏，演奏台会高亮当前音符。
7. 随时可以：
   - `F9`：开始 / 停止；
   - `F12`：**紧急停止**（立即释放所有按下的键）；
   - 软件界面的「停止」按钮。
8. 演奏结束/停止后，程序会自动释放全部按键与鼠标键。

### 安全机制说明

| 机制 | 行为 |
|---|---|
| 焦点保护 | 游戏窗口失去焦点（如 Alt+Tab、弹窗）→ 立即停手并松键 |
| 光标保护 | 鼠标离开游戏窗口 → 立即停手（否则八度/半音修饰键会失效或误点别的程序） |
| 自动切前台 | 开始前尝试把游戏窗口切到前台 |
| 全量松键 | 任何停止路径都会释放已按键 |
| 排练模式 | 设置里可选「排练模式」：只走时间轴不发送按键，用于核对节奏 |

## 5. 简谱语法速查

### 音符

| 写法 | 含义 |
|---|---|
| `1` `2` … `7` | 中音区 do–si |
| `0` | 休止符 |
| `#4` / `b7` | 升四 / 降七（游戏只有升号，降号自动用等音处理） |
| `1'` / `5''` | 高八度 / 高两个八度（以 `1` 为基准） |
| `,1` / `,5` | 低八度 / 更低（前缀逗号，可多个） |

### 时值（基础 = 1 拍，四分音符）

| 写法 | 含义 |
|---|---|
| `5` | 1 拍 |
| `5_` | 半拍（八分音符）；`5__` = 1/4 拍 |
| `5.` | 附点（×1.5） |
| `5_.` | 附点八分（0.75 拍） |
| `5-` | 2 拍；`5--` = 3 拍（延长线必须紧贴音符） |
| `5:1.25` | 精确指定 1.25 拍（MIDI/音频导入时会出现） |
| `5~ 5` | 连音线：把前一个音与后面紧邻同音连成一个长音 |
| `5~`（行尾） | 连到下一行同音 |

### 其他

| 写法 | 含义 |
|---|---|
| `\|` | 小节线（用于拍号校验与排版） |
| `// 内容` | 注释 |
| `# 标题：小星星` | 头部信息（支持：标题/艺术家/速度/拍号/调号/基础八度/备注/来源） |

**示例**：

```text
# 标题：小星星
# 速度：100
# 拍号：4/4
# 调号：1=C
# 基础八度：4

1 1 5 5 | 6 6 5- | 4 4 3 3 | 2 2 1- |
5 5 4 4 | 3 3 2- | 5 5 4 4 | 3 3 2- |
```

> 简谱的「1=?」是调号：1=C 时 `1` 为 C4；1=F 时 `1` 为 F4。移调设置会整体升降。

## 6. 编辑器操作

- **左栏文本区**：直接输入/粘贴简谱，停止输入约 0.4 秒自动解析；解析错误会列在下方（红色为错误，修复前不会更新谱面）。
- **右栏预览**：点击任意音符可选中，并在下方「音符属性」面板修改：
  - 音级（0-7）、升降、八度、时值（拍）、起始拍、连音；
  - 快捷时值按钮（0.25/0.5/0.75/1/1.5/2/3/4 拍）；
  - 删除音符、在末尾追加音符。
- **顶栏元信息**：标题、速度、调号、拍号、基础八度可改，改完谱面实时更新。
- **试听**：右栏「试听」用内置音源播放当前谱面。
- **保存方案**：写入曲库（本机用户数据目录）；标题旁会显示「有未保存修改」。
- **导入文件**：支持 `.txt` 简谱 / `.dfh.json` 方案 / `.json`。
- **导出简谱**：导出为文本。

如需从社区谱面开始：直接把简谱文本粘进文本框即可。若社区是「按键谱」（如 `MNMNCBV`），目前请先用「简谱文本」按数字录入（键位谱导入在路线图中）。

## 7. MIDI 导入

1. 打开「智能导入 → MIDI 导入」；
2. 选择 `.mid/.midi` 文件（建议单旋律轨，或主旋律清晰的轨）；
3. 程序会列出所有轨道（音符数、音域、单音比例、是否鼓轨），默认自动选最佳轨；
4. 可调整：量化精度（1/16 推荐）、调号（自动检测/指定）、标题；
5. 点轨道即可重新分析；右侧预览谱面与提示；
6. 「保存到方案库」→ 回演奏台选择它即可。

提示：

- 多轨 MIDI 会自动做「单音化」（保留高音主旋律、截断重叠）；
- 变速 MIDI 目前取第一段 BPM（会提示）；
- 超出音域的音在演奏台会被自动折返/移调，预览面板会提示数量。

## 8. 音频导入

> **重要**：音频扒谱是单声部假设。**清唱、哼唱、口哨、单乐器独奏**效果较好；带伴奏的成品歌曲容易把伴奏误判成旋律。成品歌建议用 MIDI 或直接粘贴网上的简谱文本。

1. 打开「智能导入 → 音频分析」；
2. 选择 `.mp3/.wav/.m4a/.flac/.ogg` 等音频；
3. 程序会：解码为单声道 22.05kHz → YIN 基频 → 切音 → 起音/节拍分析 → 量化 → 调性检测 → 生成简谱；
4. 可调 BPM（默认检测值）、量化精度，点击「重新生成」；
5. 检查右侧谱面与提示，必要时在编辑器里手工修正；
6. 保存到方案库。

建议录音质量：无伴奏、音量稳定、单音清晰、避免混响过大；主旋律音域控制在 C3–C6 内时识谱最准。

## 9. 音乐方案库与导出

- 搜索 / 筛选（全部、收藏、游戏任务曲、导入曲谱、手动录入）/ 排序；
- 每张卡片：演奏、编辑、导出（键位谱 / 简谱文本 / 方案 JSON）、收藏、删除；
- 「导入文件」支持 `.dfh.json`、`.json`、`.txt` 简谱、`.mid`；
- 可选「新建曲谱」直接进编辑器。

### 键位谱记号（导出的键位谱）

| 记号 | 含义 |
|---|---|
| `Z X C V B N M` | 1 2 3 4 5 6 7 |
| `,` | 高音 1 |
| `↑` | 按住鼠标右键（升八度） |
| `↓` | 按住鼠标左键（降八度） |
| `#` | 按住鼠标中键（升半音） |
| 例如 `↑Z` | 按住右键 + 按 Z |

导出示例：

```
=== 小星星 · 口琴键位谱 ===
速度 100 BPM ｜ 拍号 4/4 ｜ 1=C
键位：Z X C V B N M , = 1 2 3 4 5 6 7 高音1
修饰：↑=按住鼠标右键(高八度)  ↓=按住鼠标左键(降八度)  #=按住鼠标中键(升半音)

| Z Z B B  | N N B-  | V V C C  | X X Z-  |
...
```

（实际导出会按小节分组，`-` 表示延长记号由软件排程处理，不会出现在键位谱里。）可以把键位谱抄给朋友手动弹，或用于校对自动演奏。

## 10. 设置与校准

### 按键时序（高级）

| 参数 | 默认 | 说明 / 调整建议 |
|---|---|---|
| 修饰键稳定时间 | 24ms | 先按住鼠标修饰键，等这么久再按音符键。若高/低音偶发变成中音，适当**调大** |
| 相邻音释放间隔 | 12ms | 两音之间的空隙，避免粘连。若两音分不开，适当调大 |
| 最短保持时间 | 40ms | 单音最短按住时长。若快速音漏音/听不到，**调大** |
| 修饰键切换间隔 | 6ms | 换音时松开旧修饰键到按新键的间隔 |
| 开头留白 | 90ms | 第一个音之前的准备时间 |

调整后回演奏台重新生成计划（计划是实时计算的）。

### 其他

- **输入方式**：模拟按键注入 / 排练模式 / 串口硬件（预留，未启用）；
- **焦点保护**：强烈建议开启；
- **自动切前台**：开始前把游戏窗口切前台；
- **允许「八度键+半音键」组合**：默认开启；若实机发现半音只在中音区生效，可关闭此选项让软件按兼容模式排键（会牺牲部分半音）；
- **音频导入默认量化精度/自动调性**；
- **口琴键位表**：当前固定为 Z X C V B N M , + 鼠标三键（可在自检中确认）；
- **风险声明与官方公告链接**：设置页底部，可打开数据目录。

## 11. 故障排查

| 现象 | 可能原因 | 解决 |
|---|---|---|
| 游戏里完全没声音/没反应 | 未以管理员运行（UIPI 静默拦截） | 点状态栏「以管理员重启」，UAC 确认；状态栏应显示绿色「管理员权限」 |
| 同上 | 目标窗口选错 / 游戏不在前台 | 演奏台刷新窗口后重选；开启焦点保护并让游戏在前台；开始后 3 秒内切回游戏 |
| 部分音吹错（高/低音变成中音） | 鼠标光标不在游戏窗口内；游戏未进入手动演奏界面 | 演奏中保持鼠标在游戏窗口内；确认已掏出口琴；适当调大「修饰键稳定时间」 |
| 快速音符漏音/粘连 | 节奏过快/保持时间太短 | 调大「最短保持时间」「相邻音释放间隔」，或降低速度（速度覆盖） |
| 开始演奏后立刻停止 | 游戏窗口失去焦点 / 鼠标移出游戏窗口 | 检查焦点保护提示；不要在演奏中切窗口；把鼠标放回游戏 |
| 自检失败 | 安全软件拦截 / 未提权 / 焦点被抢 | 以管理员运行；自检时不要操作鼠标键盘；关闭会置顶抢焦点的软件；远程桌面/虚拟机环境可能限制模拟输入 |
| 列表找不到游戏窗口 | 游戏独占全屏 / 窗口未创建 | 游戏设置改为「无边框窗口」；点刷新；进入大厅或对局后再刷新 |
| 逗号键没反应 | 中文输入法拦截全角逗号 | 切英文/半角输入法；确认游戏内使用物理逗号键 |
| 音高整体不对 | 移调/调号设置不对 | 演奏台「移调」设为原调或自动；检查编辑器调号「1=?」 |
| 谱面红色错误 | 简谱文本语法错误 | 看编辑器下方诊断（行号/原因）修正 |
| 打包版双击没反应/闪退 | 被杀毒软件拦截 / 未签名 | 添加信任；从 release 目录重新解压运行；便携版同样处理 |
| 音频转谱很乱 | 带伴奏歌曲 / 混响大 | 用清唱/哼唱或单乐器录音；成品歌改用 MIDI 或粘贴简谱 |

- 使用本软件的一切后果由使用者自行承担；若不同意，请勿使用。

## 13. FAQ

**Q：官方按 R 的自动演奏能用吗？**  
A：那是官方功能，只能播放已解锁曲目，不能导入自定义谱。本软件模拟的是手动按键，性质上属于第三方模拟输入。

**Q：会被封号吗？**  
A：官方口径覆盖第三方模拟输入/脚本，存在真实风险，软件已按最高风险提示并做安全限制，但**无法保证安全**。请自行决定是否使用。

**Q：为什么软件 250MB？**  
A：Electron 运行时本身较大。换 Python/Qt 可显著减小体积，但本项目优先 UI 质量与开发效率。

**Q：能弹和弦吗？**  
A：游戏口琴是单音，不能和弦。MIDI 会自动提取单声部主旋律。

**Q：支持手游端吗？**  
A：当前只支持 PC 端键盘鼠标方案。

**Q：能自己改键位吗？**  
A：当前版本键位固定（可用自检确认）；自定义逐键重映射在路线图中。若游戏版本改键，请等预设更新。

**Q：为什么第一次开始要 UAC 提示？**  
A：游戏以管理员权限运行，注入按键必须让本程序也处于高完整性级别，否则 Windows 会把按键静默丢弃。

**Q：数据存在哪里？**  
A：`%APPDATA%\三角洲口琴工坊\`（settings.json + scores/*.dfh.json）。设置页可一键打开数据目录。

**Q：能导出给别人用吗？**  
A：可以导出 `键位谱`（照着按）或 `方案 JSON`；JSON 可在另一台电脑通过「方案库 → 导入文件」导入。
