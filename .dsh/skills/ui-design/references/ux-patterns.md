# UX 规则

## 1. 页面骨架（必须一致）

```
.page
├── PageHeader      （h1 标题 / 一句说明 / 右上操作区；不设眉标）
├── 主要内容区       （1–3 个 .card，或空态）
└── 辅助信息         （hint-text / 统计行，可选，仅在页面内独一无二时保留）
```

- 标题只出现一次（侧栏高亮 + 页面 h1 不算重复；顶栏不放页面标题）。
- 说明文字只写「这个页面能做什么 + 操作顺序」，不写实现细节。
- 页面头右侧最多 1 个主按钮；全应用的主操作「开始演奏」固定在播放条，页面内不得再做同样权重的主按钮。

## 2. 状态信息的层级（说一次原则）

| 层级 | 位置 | 内容 | 示例 |
|---|---|---|---|
| L0 全局常驻 | 顶栏 `status-pill` / 播放条 | 一个短标签（≤6 字）+ `title` 详情 | 「输入就绪」「需要管理员」 |
| L1 页面级 | 页面 `.notice` | 需要用户处理的问题 + 一个动作 | 「尚未以管理员运行」→「以管理员重启」 |
| L2 字段级 | 控件下方 `.inline-error` / `.field-hint` | 与单个输入相关 | 「速度需在 20–320 之间」 |
| L3 结果反馈 | Toast | 刚完成动作的结果 | 「已保存《…》」 |

同一事实禁止跨层重复：管理员权限只在 L0 出现短标签，详细解释放设置页；未保存只在顶栏徽标 + 播放条状态出现。

例外：L0 状态徽标与 L1 页面提示可以并存，当且仅当 L1 是**条件出现**、**携带解决动作**的决策入口（例如「当前有未保存的修改」→ 继续编辑 / 保存）。此时徽标是状态，提示是决策，不算重复。

## 3. 操作优先级

- 每个任务区最多一个 `.btn--primary`（琥珀色调）；实心琥珀 `.btn--accent` 全应用唯一，只给播放条的「开始演奏」。
- 破坏性操作（停止、删除、覆盖）用 `.btn--danger`，并且颜色之外要有明确动词。
- 停止 = 立即生效，不需要二次确认；删除曲谱这类不可撤销操作才需要确认。
- 长任务（导入、分析）按钮进入 disabled + 进行时文案，防重复提交。

## 4. 反馈与等待

- 动作在 300ms 内完成：什么都不要加。
- 超过 300ms：按钮进行时 + 局部骨架/进度文案。
- 超过 3s：给出可见进度（`.progress` 或阶段文案），并保证界面仍可操作（可取消）。
- 失败必须说明「哪一步失败 + 怎么办」，不要只显示异常字符串。示例：`导入失败：文件不是有效的 MIDI（第 2 轨无音符）`。

## 5. 空态与首次使用

- 每个可能为空的列表/面板都要有空态，禁止留白或只显示表头。
- 空态给出一个主操作，直接通向下一步（导入 / 编辑 / 选择曲谱）。
- 首次使用时，默认数据（内置示例曲）应能让核心路径一次跑通。

## 6. 表单

- 标签在上、控件在下；同一行的标签宽度对齐。
- 默认值即有效值，允许直接编辑；不要用占位符代替标签。
- 校验即时（失焦或输入防抖 400ms），不要只在提交时报错。
- 数字输入带单位提示（BPM、秒、拍），范围写进 `min`/`max` 与 `title`。

## 7. 键盘与焦点

- Tab 顺序 = 视觉顺序；不允许 `tabindex > 0`。
- 所有图标按钮必须有 `aria-label`；所有开关必须有可见文字标签。
- 弹窗：Esc 关闭、Tab 在弹窗内循环、关闭后焦点回到触发元素（`Modal` 已实现，直接复用）。
- 编辑器支持 Ctrl+S 保存；全局热键（F9/F10/Ctrl+Alt+O）在任何页面都有效，不得被输入框吞掉。
- 可见焦点环不可移除（`:focus-visible` 已有全局样式）。

## 8. 文案

- 中文界面；动宾结构，短句，句末不加句号（说明性长句除外）。
- 概念统一：演奏 / 试听 / 导入 / 方案库 / 简谱 / 键位谱 / 悬浮窗。不要混用「播放」「扒谱」「曲谱库」「小窗」。
- 数字与拉丁单位之间保留空格：`127.9 BPM`、`3 秒`、`571 音`、`-2 半音`。
- 不用全大写英文（`LIVE` 这类状态标记除外）；技术缩写（MIDI、BPM、AHK）保持原样。
- 危险操作动词放前面：「立即停止并释放所有按键」。

## 9. 密度与对齐

- 4pt 栅格；间距只取 `--sp-*` 令牌。
- 控件高度 34px，小号 28px；同一行内控件高度必须一致（输入框配按钮不要一个 34 一个 28）。
- 页面内容最大宽度 1180px 居中；不要在页面里出现第三个宽度层级。
- 长标题、长曲名：`text-overflow: ellipsis` + `title` 承载全文，禁止换行撑高工具栏。

## 10. 颜色语义

- 琥珀 = 主操作 / 选中 / 正在演奏；青 = 系统与输入通道信息；绿 = 正常；红 = 失败 / 破坏性。
- 不要用颜色单独表达状态，必须配文字或图标。
- 强调色面积控制在视口 5% 以内；大面积琥珀只允许出现在主按钮。

## 11. 动效

- 页面进入 240ms、微交互 120–180ms，缓动 `--ease-out`。
- 只做位移动画（≤6px）与透明度，不做缩放弹跳。
- 正在演奏/倒计时可以有呼吸/脉冲，但 `prefers-reduced-motion` 下必须静止。
