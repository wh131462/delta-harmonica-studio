# 设计令牌

唯一实现在 `src/renderer/src/styles/tokens.css`。本文件说明**为什么**这样取值、**什么时候**用哪个令牌。数值变更只改 tokens.css，并同步更新本表。

## 色彩

### 中性（冷石墨，蓝相极低）

| 令牌 | 值 | 用途 |
|---|---|---|
| `--canvas` | `#07080b` | 窗口最底层、原生窗口背景（`main/index.ts` 的 `backgroundColor` 必须与之一致） |
| `--canvas-elev` | `#0a0c11` | 页面滚动区背景 |
| `--surface-1` | `#0d1015` | 侧栏、播放条 |
| `--surface-2` | `#11141b` | 面板 / 卡片 |
| `--surface-3` | `#161a22` | 次级按钮、标签、悬停底 |
| `--surface-4` | `#1c212b` | 悬停、Toast 底 |
| `--surface-5` | `#232935` | 按下、滑杆轨道 |
| `--surface-inset` | `#0b0e13` | 输入框、分段控件、只读数据块 |
| `--surface-veil` | `rgba(13,16,21,.82)` | 顶栏 / 播放条的半透明层 |

层级靠 **表面明度** 区分，不靠阴影也不靠描边；描边只出现在可交互控件的边界上（输入框、次级按钮、分段控件）。阴影只用于浮层（弹窗、Toast）。

### 文本

| 令牌 | 值 | 对比度（在 `--surface-2` 上） | 用途 |
|---|---|---|---|
| `--text-1` | `#e9edf4` | ≈ 13.9:1 | 标题、正文、数值 |
| `--text-2` | `#a7b0bf` | ≈ 7.6:1 | 次要文本、未选中导航 |
| `--text-3` | `#78828f` | ≈ 4.7:1 | 说明、标签、占位提示 |
| `--text-4` | `#59616f` | ≈ 2.9:1 | 仅装饰/禁用，不得承载关键信息 |
| `--text-on-accent` | `#1a1204` | — | 琥珀底上的文字 |

### 强调与语义

| 令牌 | 值 | 用途 |
|---|---|---|
| `--accent` | `#f2b64a` | 主操作、选中、正在演奏 |
| `--accent-hover` / `--accent-press` | `#ffc866` / `#dda23a` | 按钮状态 |
| `--accent-soft` / `--accent-line` | `rgba(242,182,74,.12/.42)` | 浅底 / 描边 |
| `--signal` | `#5cc8e8` | 输入通道、焦点、链接型诊断 |
| `--ok` | `#43d39e` | 就绪、成功 |
| `--warn` | `#efb35c` | 需要留意、未完成 |
| `--danger` | `#f4777a` | 失败、破坏性、急停 |
| `--focus` | `rgba(92,200,232,.75)` | 焦点环（2px 外扩 2px） |

每种语义色都有 `-soft`（12% 透明底）和 `-line`（36–40% 描边）配对，用于徽标/提示条。**不要**用强调色做装饰性描边或图标着色。

### 谱面

`--paper #16130f`（暖黑纸面）、`--paper-2 #1a1712`、`--paper-ink #f1e7d5`、`--paper-ink-dim #a89b86`、`--paper-rest-ink #cbbda6`、`--paper-barline #4c453b`、`--paper-barline-strong #b8a98f`、`--paper-tie #8d806c`。谱面是界面中唯一的暖色区域，用「灯下纸面」呼应守夜人主题；`.score-surface` 把这些映射到 `ScoreView` 的 `--sv-*` 变量（见 `components.css`）。

## 字体

| 用途 | 令牌 | 规格 |
|---|---|---|
| 页面标题 | `--fs-display` 26px / 1.2 / 640 | 每页仅一个 |
| 区块标题 | `--fs-title` 17px / 1.35 / 600 | 卡片标题、弹窗标题 |
| 小标题 | `--fs-subtitle` 14px / 1.45 / 600 | 卡内分组 |
| 正文 | `--fs-body` 13px / 1.6 | 默认 |
| 导语 | `--fs-lead` 12.5px / 1.55 | 页面头说明（`.page-header p`） |
| 次要 | `--fs-sm` 12px / 1.55 | 按钮、说明 |
| 辅助 | `--fs-xs` 11px / 1.45 | 标签、元信息 |
| 微型标签 | `--fs-micro` 10px / 600 / 字距 .14em / 大写 | `.section-label`（分组标签；页面头不使用眉标） |
| 指标数字 | `--fs-metric` 20px / 600 / 1.2 | `.stat-value`、大号计数 |

- 字体族：`--font-sans`（Segoe UI Variable → 微软雅黑 → PingFang/Noto）；`--font-display` 仅用于标题；`--font-mono` 用于简谱文本、快捷键、代码、时间码。
- 所有数字对齐处加 `.num`（`font-variant-numeric: tabular-nums`），避免数值跳动。
- 中文正文行高不低于 1.55；微型英文标签可以到 1.3。

## 间距（4pt 栅格）

`--sp-1..--sp-16` = 4, 8, 12, 16, 20, 24, 32, 40, 48, 64。

- 卡片内 padding 20；卡片间距 20（由 `.page` gap 提供）。
- 图标与文字 6–8；标签与控件 6；同组字段 12；分组之间 20–24。
- 只允许上述值，不要出现 5/7/13/18 这种手写值。

## 圆角

`--r-xs 5`（徽标）· `--r-sm 7`（小按钮、导航项）· `--r-md 9`（按钮、输入框）· `--r-lg 12`（提示条、谱面夹）· `--r-xl 16`（弹窗、启动图标）· `--r-panel 14`（卡片）· `--r-full`（胶囊）。

## 阴影

`--shadow-inset`（按钮/输入框的 1px 高光）· `--shadow-2`（Toast）· `--shadow-3`（弹窗）· `--accent-glow`（仅悬浮窗主按钮）。卡片、页面背景、播放条不使用阴影。

## 控件尺寸

`--h-control 34` · `--h-control-sm 28` · `--h-control-lg 40` · `--h-icon-button 32`。

## 动效

`--dur-1 120ms`（悬停/颜色）· `--dur-2 180ms`（开关/展开）· `--dur-3 260ms`（页面/弹窗）· `--ease-out`（进入）· `--ease-in-out`（状态切换）。

## 层级

`--z-dock 20` · `--z-popover 80` · `--z-overlay 100` · `--z-modal 120` · `--z-toast 200`。不要写裸 z-index。

## 布局

`--sidebar-w 232` · `--topbar-h 48` · `--dock-h 72` · `--page-max 1160` · `--page-pad-x 32` · `--page-pad-y 28` · `--card-pad 20`（卡片内边距，`--card-pad` 是唯一入口，导入页吸底执行区也按它计算负边距）。

响应式分档（宽度）：
- **≤1280**：侧栏 216，页面左右内边距 24，隐藏热键提示。
- **≤1180**：页面改单列（演奏 / 练习 / 设置 / 编辑器），播放条隐藏音量与时间码，导入执行区回到文档流。
- **≤1120**：左右内边距 20，顶栏「悬浮窗」只留图标，单列表单控件最大宽度 420–520，方案库卡片网格改用 `auto-fill minmax(240px, 1fr)`。
- **≤1080**：侧栏折叠为 68px 图标轨；导航文字隐藏，LIVE / 未保存改为角标圆点，管理员状态保留为图标按钮（`title` / `aria-label` 承载全文）。
- **≤1000**：方案库列表隐藏参数列。
- **≤760**：弹窗贴近窗口边缘，工具栏 / 空态 / 通知操作允许换行。

响应式分档（高度）：
- **≤800**：顶栏 44、播放条 64、页面上下内边距 16、`--card-pad` 16；谱面 / 练习轨道 / 导入预览等固定高度同步收紧。

窗口最小尺寸 **1024×720**；最小宽度下侧栏为图标轨，1280 及以上使用完整侧栏。
